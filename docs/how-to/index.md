# How-to guides

Task-oriented. These assume you know what you are doing and want the commands.

- **[Set up VS Code](vscode-setup.md)** — free extensions, build/flash/debug
  without leaving the editor, and how this setup differs from HAW Hamburg's
  other ITSboard example.
- **[Build the firmware](build.md)**
- **[Flash the board](flash.md)**
- **[Run the hardware gate](board-test.md)**
- **[Debug with GDB](debug.md)**
- **[Configure the firmware](configure.md)** — edit `/config.txt` from a host, and build an image with only the features you want.
- **[Work an issue as an agent](agent-workflow.md)** — how parallel contributors
  are expected to operate, and why they must not touch the hardware.

For the reasoning behind any of it, see [Explanation](../explanation/index.md).
