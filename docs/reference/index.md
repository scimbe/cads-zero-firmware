# Reference

Information-oriented and deliberately dry. Look things up here.

- **[Hardware](../HARDWARE.md)** — what the board is, the full pin map, the
  display bus topology, and the comparison against a Flipper Zero.
- **[Safety rules](../SAFETY.md)** — binding constraints. Read before touching a
  peripheral, a flash address, or an option byte.
- **[Memory map](memory-map.md)** — flash banks, RAM regions, what may and may
  not be a DMA target.
- **[Canvas API](canvas.md)** — the drawing surface.
- **[HAL interface](hal.md)** — the boundary between portable code and the two
  backends.
- **[Measurements](measurements.md)** — numbers taken from the physical board,
  with the conditions they were taken under.
